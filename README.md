## ⚡ Mobile Engine Features
- **Touch-Optimized Controls:** Full-screen responsive touch targeting, tap-to-splat mechanics, and virtual active ability triggers (`Sigma Blast`, `TV Hypno`, `Bass Drop`).
- **2.5D Physical Defense Floor:** Ground perspective with physical unit physics, spring bounce traps, and cascading ragdoll collisions.
- **Apex Sentinel 99% (BugManager & BugHandler):** Real-time 200ms glitch interception engine with self-healing invariants.
- **GameManagers Suite:**
  - `Juice`: Dynamic hitstop, critical impact frames, and screen shakes.
  - `AdaptiveDirector`: AI horde pacing with clutch comeback buffers.
  - `SoundDirector`: Spatial stereo audio panning and combo pitch escalations.
  - `SaveManager`: Dual-slot fail-safe save redundancy.
- **Titan Alliance Cadre:** Summon walking ground units (Titan Cameraman, Titan Speakerman, Titan TV Man, Titan Drillman).
- **Infinity Mode & 3D G-Man 1.0 Boss:** Real-time Three.js 3D boss encounters at Wave 100+.
